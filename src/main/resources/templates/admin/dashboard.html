🛠️ What you can do as Admin
➕
Create Events

Click Create New Event or go to Manage Events → New Event. Fill in title, description, date, venue, department, type and capacity.

✏️
Edit Events

Go to Manage Events, find the event in the table and click Edit. You can also change the event status (Upcoming → Completed / Cancelled).

🗑️
Delete Events

In the events table click the red delete button. A confirmation dialog will appear before the event is permanently removed.

👥
View Registrations

Click the Regs button on any event to see every student who registered, their status and feedback rating.

🔍
Search & Filter Events

Use the filter bar on Manage Events to narrow by department, type, status, date range or keyword — all filters combine.

📊
View Statistics

Go to Statistics for live charts — events by type, by department, by status — and a top-5 events leaderboard by registrations.
